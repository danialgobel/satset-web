# Satsetwell — Creative Brotherhood Archive

Modern, cinematic, dark luxury web archive for the Satsetwell collective. Built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

## Features
- **Prisma Aesthetic**: High-contrast dark luxury theme with warm cream typography (`#DEDBC8` / `Almarai` font).
- **Interactive Intro Splash**: Snappy typewriter animation for `Satsetwel*` and Apple Glass "Ketuk untuk memulai" button.
- **Cinematic Hero**: 1080p documentary video with noise overlay, custom vignette, and mobile-friendly widescreen framing.
- **Synced Background Music**: Steve Lacy — *oh yeah* playing at second 10 with smooth fade-in, automatically fades out during video playback and resumes seamlessly on close.
- **High-Res Media Archive**: Full 4K photo gallery with instant 0ms category switching and high-definition lightbox viewer.
- **Member Collective**: Interactive member profiles with direct Instagram links.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
